#  AI Quiz

An interactive quiz application built with Python, FastAPI, HTML, CSS, and JavaScript. It uses a locally running AI model through Ollama to generate educational fun facts after each answer.

##  Features

- Multiple-choice quiz with 20 questions.
- Interactive web interface.
- Automatic score tracking.
- Immediate answer feedback.
- AI-generated educational fun facts.
- Local AI inference using Ollama and Qwen 2.5:3B.
- REST API built with FastAPI.
- API documentation available through Swagger UI.
- Docker support for containerized deployment.
- GitHub Actions CI to run automated tests on pushes and pull requests.
- Automated tests using pytest and FastAPI TestClient.

Statement on the Use of Artificial Intelligence (AI)
This project was developed with the assistance of ChatGPT, a large language model developed by OpenAI. AI assistance was utilized across the following phases of development:
• Software Development: The core logic of the front-end JavaScript (script.js) and the entire backend server logic (server.py) were generated by the AI tool based on prompt requirements.
• Debugging & Optimization: Errors during local server testing and data communication were resolved using AI-guided troubleshooting.
• Configuration & Deployment: The project's .gitignore file was entirely written by the AI. Additionally, step-by-step guidance was provided by the AI to initialize git repositories, commit files, and successfully push the source code to GitHub.
• System Design: The AI acted as a technical advisor, recommending architecture patterns and project structuring.
